# 🎮 EmulatorHub Controller Quick Reference

```
┌─────────────────────────────────────────────────────────────┐
│                  CONTROLLER BUTTON MAPPING                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   D-Pad / Left Analog Stick                                │
│   ├─ ↑ UP        → Navigate up in game list               │
│   ├─ ↓ DOWN      → Navigate down in game list             │
│   ├─ ← LEFT      → Focus platform list                     │
│   └─ → RIGHT     → Focus game list                         │
│                                                             │
│   Face Buttons                                             │
│   ├─ Ⓐ (A/Cross)      → Launch selected game              │
│   ├─ Ⓑ (B/Circle)     → Toggle favorite                   │
│   ├─ Ⓧ (X/Square)     → Show game info                    │
│   └─ Ⓨ (Y/Triangle)   → Focus search bar                  │
│                                                             │
│   Shoulder Buttons                                         │
│   ├─ LB (L1)     → Previous tab                           │
│   └─ RB (R1)     → Next tab                               │
│                                                             │
│   Menu Buttons                                             │
│   └─ START       → Refresh game library                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘

COMPATIBILITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ Xbox Controllers (Xbox One, Xbox Series X/S, Xbox 360)
✓ PlayStation Controllers (DualShock 4, DualSense)
✓ Nintendo Controllers (Switch Pro, Joy-Cons)
✓ Generic USB/Bluetooth Controllers
✓ Steam Controller
✓ 8BitDo Controllers

SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Connect controller via USB or Bluetooth
2. Launch EmulatorHub
3. Controller automatically detected
4. Start navigating!

CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
config.json settings:
  "controller_enabled": true/false
  "controller_deadzone": 0.2 (0.0 - 1.0)

TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Use analog stick for smooth navigation
• D-pad for precise selection
• Combine with keyboard for advanced features
• Controller works alongside mouse/keyboard

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Controller not responding?
  → Ensure pygame is installed
  → Try reconnecting controller
  → Restart EmulatorHub
  → Check controller works in other apps

Analog stick too sensitive?
  → Increase deadzone in config.json
  → Default: 0.2, try 0.3 or 0.4

Wrong button mappings?
  → EmulatorHub uses standard mappings
  → Check controller in Windows Game Controllers
  → Some third-party controllers may vary
```
